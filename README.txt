Sharitoo — мод-лаунчер для Super Bear Adventure (Android)

Как получить APK:
1) Android Studio: File > Open > папка Sharitoo > Build > Build APK(s).
   APK будет в app/build/outputs/apk/debug/app-debug.apk
2) Без Android Studio: залей папку в свой репозиторий на GitHub,
   вкладка Actions > Build APK > скачай Sharitoo-apk.
Установка: разреши "Установку из неизвестных источников" и открой APK.

Кнопка "Играть" ищет установленное приложение с названием "Bear Adventure".
Если у игры другое название — поменяй gameLabel в MainActivity.kt.
Интерфейс лежит в app/src/main/assets/index.html.
